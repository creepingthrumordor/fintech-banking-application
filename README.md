# FinTrust

A Flutter banking app prototype based on the screens in `Wireframe/`. It includes
responsive layouts for the dashboard, transfers, cards, activity, personal
finance, smart search, services, support, and account settings.

## Run

```sh
flutter pub get
flutter run
```

The prototype uses local demo data only. Transfers update the in-memory balance
and activity feed; authentication, QR scanning, bill payments, and other
banking operations are demonstrations and are not connected to financial
services.

Screen changes, tab selection, dashboard content, and activity filters use
short, low-key animations to keep interactions responsive without slowing down
common banking tasks.
